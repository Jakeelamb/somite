# Keep imported workflows flat and traverse groups with semantic zoom

Somite represents an imported Nextflow workflow as one compact Workflow instance on the main Graph. That instance contains a live miniature of its source-anchored Workflow outline. Cursor-centered zoom grows the preview until the same persistent canvas rebases into one complete, normal readable graph: every indexed invocation call and known relationship is visible by default, with no automatic hulls or source-AST containment. Zooming outward applies the exact inverse camera transform. The canvas host, grid, tools, Agent, and interaction model never change, and no alternate header, breadcrumb strip, modal, or open button is introduced. Workflow, subworkflow, and process scopes remain quiet provenance and grouping-suggestion metadata rather than visible container cards. The immutable pinned source plus explicit user edits remains executable truth. DOT output may assist presentation or cross-check an outline, but Somite never compiles a flattened DOT reconstruction because it loses channel transformations, composite values, conditions, hierarchy, configuration, and task environments.

The projection preserves relationship honesty. Executable typed dataflow Edges remain distinct from dashed, nonconnectable Source-structure relationships. Each indexed invocation appears once, including unresolved calls with their exact source anchors; shared or cyclic scope metadata never duplicates a call card. A readable projection must not imply that every displayed process can run independently or that source invocation structure is a typed channel contract.

Nesting is an explicit user action over an arbitrary entity or relationship selection, not a property inferred from the upstream AST. A selected relationship contributes its exact canonical endpoints; relationships shown within, across, or outside the resulting group are then derived from those retained identities. Accepting a Source-scope suggestion invokes the same grouping action as `Nest selection`; it does not grant Source structure ownership over the canvas. Expanded groups appear as soft hull overlays, so their members keep normal card dimensions and the original relationships stay readable. Group membership is stored in a separate presentation forest rather than source entities or a canvas-node `parentId`, which permits arbitrary depth without turning visual containment into workflow semantics.

Collapsing a hull creates a non-executable Macro with a live miniature of its members. Relationships that cross its boundary are shown as proxy relationships that retain the exact underlying relationship and member endpoints; they are not new Edges and cannot be connected. Expanding restores the same visible source entities and relationships. Soft hulls and Macros are recursive Semantic portals: once one fills the viewport, its members become the active frame and crossing relationships terminate at exact boundary portals. Moving a member out, moving it back, renesting it elsewhere, or ungrouping changes only presentation membership and never deletes, duplicates, or rewrites a source entity, relationship, or provenance anchor.

Source-group membership, nesting, collapse, and placement are persisted and undoable document presentation. They participate in Graph state revision but remain excluded from semantic Graph revision, Run closure, and Evidence receipt identity. This state must round-trip without inventing missing source structure; malformed groups fail closed rather than dropping members or leaving a visible relationship with no endpoint.

The source Semantic frame is permissively editable. A user may replace an invocation before Somite knows every channel contract; the edit creates a Workflow variant anchored to the original invocation, and every unknown connection remains explicit rather than blocking creativity. Typed contracts power automatic rewiring and Logic checks, not permission. Catalog operator revisions and Pixi requirements freeze the tools selected by the variant. Representative validation remains the proof that a modified workflow works; connected, environment-ready, plausible, and validated are distinct states.

Source bytes remain raw blobs from the exact resolved commit tree; mutable worktree files, Git status, and checkout filters are outside provenance. An Invocation replacement never mutates those bytes or erases the upstream definition. Export and execution must consume the variant edits or report them as unresolved; Somite must never show a cosmetic replacement while silently running the original source.

A whole-root source may execute without promotion only when the immutable tree carries one complete root Pixi manifest and lock, that lock includes Nextflow and OpenJDK, and static inspection finds no external per-task environment directive. Somite adopts, rather than re-solves, this environment. Nextflow preview validation proves only source compilation and DAG construction; an ordinary Run is still required to execute tasks. Parameter-schema editing is an independent capability and blocks execution only when an actual required value remains unresolved.

An Invocation promotion crosses into the separate Native workflow variant model described by ADR 0006. The retained source then becomes provenance rather than a partially executed layer beneath the native graph.
