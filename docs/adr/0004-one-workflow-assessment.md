# Use one workflow assessment across product surfaces

Somite will compute `WorkflowAssessment` once from a pinned Graph and Catalog.
Paper review, Readiness, Export, run admission, MCP, and contextual Agent
handoff will consume that same value. The assessment owns ordered requirements,
Node support states, exact input controls, known resolutions, portable recipes,
and escalation eligibility. Scientific evidence remains a separate paper claim
and validation receipts remain separate execution evidence.

Exceptional operators may publish versioned Resolution recipes. Recipes travel
with the assessment and frozen bundle, but they are reviewed guidance rather
than hidden execution. Direct file attachment and parameter entry update the
Graph and recompute the assessment; no UI surface may locally declare a
requirement cleared.

Maintaining separate Paper, Readiness, Export, or Agent classifiers is rejected
because labels and blocking behavior can drift. Sending every missing input to
AI is also rejected: deterministic file, parameter, and connection work stays
inside Somite. Agent escalation is exposed only when the assessment marks a
scientific choice, Managed-resource tradeoff, legacy environment, or missing
reviewed contract as requiring interpretation.
